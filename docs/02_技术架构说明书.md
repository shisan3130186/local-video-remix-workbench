# 技术架构说明书

> 文档定位：下方 V0.1 内容是初始架构基线。当前项目已经在相同分层和 VideoEngine 边界上完成 AI 文案智能混剪 MVP；最新状态和安全约束以根目录 `README.md`、`PROJECT_STATUS.md`、`DECISIONS.md` 为准。

## 架构原则

前端只负责界面和用户交互。
视频处理必须走统一 VideoEngine。
耗时任务必须走任务队列。
API Key 不允许明文保存。
会员卡密不允许纯本地判断。

当前阶段先做 V0.1 基础可运行版，目标是打通：

```text
FFmpeg 检测 → 导入素材 → 读取信息 → 视频预览 → 基础导出 → 任务日志
```

## 模块划分

- UI 层：页面和组件
- Service 层：业务逻辑
- VideoEngine 层：FFmpeg / FFprobe 封装
- Task 层：任务队列、进度、日志
- Storage 层：SQLite / 本地配置

## 分层说明

### 1. UI 层

负责：

1. 页面展示。
2. 用户点击、选择、输入。
3. 视频列表展示。
4. 视频预览展示。
5. 任务状态展示。
6. 错误提示展示。

禁止：

1. 直接拼接 FFmpeg 命令。
2. 直接处理复杂视频逻辑。
3. 直接保存 API Key 明文。

### 2. Service 层

负责：

1. 组织前端业务流程。
2. 调用 Tauri command。
3. 整理 UI 需要的数据格式。
4. 管理前端状态。

说明：
Service 层可以理解为页面和本地能力之间的中间层。页面只告诉 Service 用户想做什么，Service 再去调用后端能力。

当前前端按功能逐步收拢到 `src/features`。AI 混剪位于 `src/features/ai-remix`：组件负责展示，`useAiRemix` 负责状态和流程，Service 负责 Tauri 调用，专用类型不再散落在 `App.vue`。

### 3. Tauri 层

负责：

1. 文件选择。
2. 本地路径访问。
3. 调用本地命令。
4. 连接前端和本地系统能力。
5. 向前端返回结构化结果。

说明：
Tauri 是前端和电脑本地能力之间的桥。

### 4. VideoEngine 层

负责：

1. 检测 FFmpeg / FFprobe。
2. 读取视频信息。
3. 基础导出。
4. 后续切片、拼接、字幕、音频处理。

禁止：

1. 让页面组件绕过 VideoEngine 直接调用 FFmpeg。
2. 把同一种 FFmpeg 调用散落在多个地方。

### 5. Task 层

负责：

1. 管理耗时任务。
2. 记录任务状态。
3. 记录任务进度。
4. 记录任务日志。
5. 记录失败原因。

V0.1 只做单任务顺序执行，不做复杂并发。

### 6. Storage 层

负责：

1. 保存用户设置。
2. 后续保存素材记录。
3. 后续保存任务记录。
4. 后续保存导出记录。
5. 后续保存混剪模板和字幕样式。

说明：
V0.1 可以先不强行引入复杂数据库结构，但代码结构要给 SQLite 留位置。

## 数据边界

### 视频素材信息

建议字段：

1. 文件路径。
2. 文件名。
3. 文件大小。
4. 视频时长。
5. 分辨率。
6. 帧率。
7. 是否有音频。
8. 导入时间。

### 任务信息

建议字段：

1. 任务 ID。
2. 任务类型。
3. 任务状态。
4. 输入文件。
5. 输出文件。
6. 进度。
7. 日志。
8. 错误信息。
9. 开始时间。
10. 结束时间。

### 设置项

建议字段：

1. FFmpeg 路径。
2. FFprobe 路径。
3. 默认输出目录。
4. 默认导出格式。
5. 日志保留策略。

## API Key 安全原则

后续 API Key 不能明文保存到普通文件、日志或数据库明文字段。

推荐方向：

1. 优先使用系统安全存储。
2. 数据库只保存服务商、名称、状态、创建时间等非敏感信息。
3. 日志中永远不输出完整 API Key。

## 会员卡密原则

会员卡密不能只靠本地判断。

原因：
如果完全写在本地，用户可以通过修改配置、数据库或代码绕过校验。

后续应该考虑：

1. 远程校验。
2. 有效期校验。
3. 设备绑定。
4. 服务端签名。
5. 本地只做状态缓存。

## V0.1 技术边界

V0.1 只允许围绕基础可运行闭环开发：

1. FFmpeg / FFprobe 环境检测。
2. 视频导入。
3. 视频信息读取。
4. 视频预览。
5. 输出目录选择。
6. 基础导出。
7. 任务进度和日志。

V0.1 不开发：

1. 会员系统。
2. API Key 系统。
3. AI 内容理解。
4. TTS。
5. ASR 字幕识别。
6. 高级去水印。
7. 复杂画中画。
8. 云端渲染。
9. 支付系统。
