# 竞品复刻基准

本目录是“智剪”复刻工作的可验收依据。它只保存从用户提供的文档、演示和截图中整理出的可观察规格；不保存竞品安装包、源代码、浏览器会话、密钥或大体积视频副本。

## 本阶段目标

第一阶段冻结桌面端视觉与交互基准，后续每一页实现均以此处文档进行比对。验收以 `1440×900` 和 `1280×720` 两个窗口尺寸为准，优先保证零素材、导入素材、设置展开和任务执行四类状态。

## 文档入口

- [UI 基准](UI_BASELINE.md)：页面尺寸、三栏结构、颜色、文字层级和控件规格。
- [页面结构](PAGE_TOPOLOGY.md)：页面及组件归属，避免把所有功能继续堆进 `App.vue`。
- [交互行为](BEHAVIORS.md)：每个入口的触发、状态变化和完成结果。
- [资源台账](ASSET_INVENTORY.md)：参考资源的位置、准备方式和程序内落点。
- [验收矩阵](VALIDATION_MATRIX.md)：逐屏、逐状态、逐尺寸的检查清单。
- [精确范围](EXACT_APPROXIMATE.md)：哪些内容必须按观察结果精确实现，哪些需要真实服务或素材后再校准。
