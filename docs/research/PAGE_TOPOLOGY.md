# 页面结构

## 一级页面

| 页面 | 进入方式 | 共用结构 | 现有主要组件 | 下一步重点 |
| --- | --- | --- | --- | --- |
| 首页 | 启动、返回首页 | 顶栏、功能分流、账号入口 | `HomePage.vue` | 首次使用引导、临期提示和菜单状态对齐 |
| AI 智能混剪 | 首页“AI 成片” | 三栏 + 任务底栏 | `AiSourceSidebar.vue`、`PreviewPanel.vue`、`RightToolPanel.vue` | 完整素材文件夹规则、匹配模式、任务阶段与草稿导出 |
| 视频混剪 | 首页/顶栏“批量混剪” | 三栏 + 任务底栏 | `BatchWorkspacePanel.vue` | 随机规则、三输入模式、批量输出一致性 |
| 分类混剪 | 批量混剪内分流 | 三栏 + 分类列表 | `BatchWorkspacePanel.vue` | 分类顺序、每类独立抽取规则 |
| 视频效果 | 首页任务入口 | 三栏 + 输出规格 | `VideoToolsWorkspace.vue`、`ToolSettingModal.vue` | 效果卡片、智能分割、输出分类与进度 |
| 内容提炼 | 首页任务入口 | 三栏 + 片段列表 | `VideoToolsWorkspace.vue` | 批量长视频、AI/手动切片、五种风格与成片 |
| 效率工具 | 首页“效率工具” | 单任务工作台 | `src/features/*` | 统一输入预览、结果与返回状态 |
| 个人中心 | 顶栏账号入口 | 双栏设置弹窗 | `src/features/membership/*` | 会员期限、卡密、设备绑定、设置入口细节 |

## 共用组件边界

| 能力 | 应放位置 | 不应放位置 |
| --- | --- | --- |
| 页面路由与跨工作区状态 | `App.vue` | 具体工作台的业务实现 |
| 三栏布局、顶栏、结果抽屉、任务队列 | `src/components` 或独立布局组件 | 每个功能复制一套 CSS |
| 素材、文案、AI 匹配、输出规则 | `src/features/<feature>` | `App.vue` 或全局样式文件 |
| 视频处理和渲染 | Rust `VideoEngine` | 前端直接拼接 FFmpeg 命令 |
| 图标和可复用视觉资源 | `public/` 或 `src/assets/`，配资源台账 | 临时目录、测试结果目录或第三方网络直链 |

## 响应式规则

该项目是 Windows 桌面端，优先保证 1280px 以上的三栏工作台。小于此宽度时只允许局部面板滚动或任务抽屉覆盖，不压缩视频画布、不让文字重叠；移动端不作为本阶段验收目标。
