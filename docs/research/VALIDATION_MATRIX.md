# 视觉与交互验收矩阵

## 固定环境

| 项目 | 值 |
| --- | --- |
| 设备 | Windows 桌面端 Tauri 程序 |
| 主窗口 | `1440×900`、`1280×720` |
| 主题 | 深色、浅色、跟随系统 |
| 测试素材 | `E:\Workspace\测试素材库` |
| 测试结果 | `E:\Workspace\测试结果库\Project_03_本地短视频批量混剪工作台` |

## 必验状态

| 页面 | 空状态 | 有素材/已配置 | 任务进行中 | 完成或失败 |
| --- | --- | --- | --- | --- |
| 首页 | 首次欢迎与六入口 | 账号/会员状态 | 不适用 | 教程与设置可返回 |
| AI 智能混剪 | 导入、预览、文案区可见 | 三种模式、视频预览、右栏设置 | 阶段、进度、取消、任务抽屉 | 预览、打开目录、草稿导出、失败重试 |
| 视频效果 | 导入入口与预览画布 | 效果开关、分割规则、输出规格 | 素材数与完成数 | 输出分类和失败说明 |
| 视频混剪 | 文件夹导入入口 | 组合规则、批量数量、预览 | 多条任务进度 | 结果列表 |
| 分类混剪 | 分类引导 | 分类顺序与独立规则 | 分类处理进度 | 每类结果可追踪 |
| 内容提炼 | 导入长视频 | AI/手动切片及片段预览 | 分析阶段 | 切片成片导出 |
| 效率工具 | 真实输入预览 | 可编辑配置 | 必要时显示进度 | 可查看、导出或打开结果 |

## 判定标准

1. 两种窗口尺寸下，页面不出现无意义的全页横向滚动，文字、按钮和面板不互相遮挡。
2. 视频类页面的导入、切片、AI 分镜和成片步骤都有真实画面预览；预览不能被三栏挤没。
3. 原始状态与实现状态要在相同窗口、相同主题、相同素材和相同交互阶段截图比较。
4. 每轮只修复一个最显著的可见或可用性差异，再截图复查。
5. 前端界面变更至少运行 `corepack pnpm build`；涉及 Rust 时再运行项目规定的 Rust 检查。
6. 测试截图按“日期_模块_窗口尺寸_状态”命名，保存到标准测试结果库。
