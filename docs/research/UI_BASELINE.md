# UI 基准

## 1. 全局桌面框架

| 项目 | 基准 |
| --- | --- |
| 主验收窗口 | `1440×900`、`1280×720` |
| 顶栏 | 固定 48px，高度内只保留返回、品牌、一级工作区、账号与辅助入口 |
| 主背景 | 深灰黑工作台，预览画布为纯黑，面板与背景只保留一层低对比区分 |
| 外层留白 | 主工作区左右 12px、上下 10px；面板间距 10px |
| 面板边框 | 1px 低对比灰线；圆角 4～6px；不使用悬浮大阴影 |
| 强调色 | 青绿色，用于选中、进度、开关、关键按钮和成功状态 |
| 信息密度 | 小字号、紧凑分组、设置默认直出；不使用营销式大卡片 |

## 2. 三栏工作台

AI 智能混剪、视频混剪、分类混剪、视频效果和内容提炼共享三栏思路：左边放来源，中间完成看与编辑，右边放可折叠的参数。当前实现的桌面轨道为左 `348px`、中间弹性且最小 `520px`、右 `304px`，栏间距 `10px`；这是后续所有工作台的固定下限。

| 区域 | 责任 | 固定表现 |
| --- | --- | --- |
| 左栏 | 导入、文件夹、素材、分类或步骤 | 可滚动；顶部放导入按钮；空状态明确下一步 |
| 中栏上部 | 视频或图片预览 | 永远可见；黑色画布；竖屏按可用高度完整显示 |
| 中栏下部 | 文案、分镜、片段、处理列表 | 与预览独立滚动；无素材时仍可说明需要做什么 |
| 右栏 | 基础设置、音频、字幕、画面处理、输出 | 分组卡片纵向滚动；常用设置不藏在深层弹窗 |
| 底部 | 创建任务、进度、结果入口 | 独立于内容区；运行时显示阶段、数量、取消和失败重试 |

## 3. 控件规格

| 控件 | 基准 |
| --- | --- |
| 普通按钮 | 28～32px 高，4px 圆角，深色填充或透明边框；图标优先于冗长文字 |
| 主操作 | 青绿色低饱和填充或描边，禁用状态降低对比和可点击性 |
| 分段选择 | 两到三个等宽选项，选中项有青绿色底和清晰文字对比 |
| 开关 | 约 38×20px，开启后使用强调色；旁边保留文字说明 |
| 滑杆 | 细轨道，右侧显示当前数值；不能只靠颜色说明范围 |
| 输入框与下拉 | 28～32px 高，深色底、细边框；路径和长文本省略显示但可完整查看 |
| 设置卡片 | 内边距约 12px，标题 10～11px，内容按 8～10px 间距排列 |
| 空状态 | 图标、短标题、一步说明；不把预览区替换成纯文字或灰色方块 |

结果、日志和任务队列使用右侧抽屉：从顶栏下方 `64px` 开始铺满到底部，任务队列约 `320px`，普通结果约 `420px`，日志约 `560px`；直角贴边，不使用右下角浮层遮挡预览。

## 4. 字体与层级

| 内容 | 建议字号 | 颜色层级 |
| --- | ---: | --- |
| 页面/面板标题 | 11～13px | 主文字 |
| 设置标题与按钮 | 10～11px | 主文字或次主文字 |
| 辅助说明、路径、统计 | 9～10px | 低对比辅助文字 |
| 预览空状态标题 | 11～12px | 主文字 |
| 状态/危险提示 | 10～11px | 成功青绿、警告黄、失败红，同时配合文字 |

不使用视口单位缩放字体；中文显示优先保证不截断、不重叠，窄窗口时允许换行或把次要文字收进工具提示。

## 5. 页面视觉重点

| 页面 | 第一视觉重点 | 必须保留的细节 |
| --- | --- | --- |
| 首页 | 六类任务入口与首次使用引导 | 功能按任务分流；右上角账号、教程与设置入口；会员临期提示 |
| AI 智能混剪 | 左素材、中预览+文案、右设置 | 本地/云端匹配切换；自定义/文案/音频三种输入；任务结果抽屉 |
| 视频效果处理 | 当前素材预览和效果设置 | 智能配置、效果启停、切割规则、输出规格和处理进度 |
| 视频混剪 | 素材组与重组预览 | 随机组合、文案/音频/自定义模式、批量数量与输出设置 |
| 分类混剪 | 分类顺序和每类抽取规则 | 每个分类独立设置；输出严格遵守分类顺序 |
| 内容提炼 | 当前长视频、片段列表和分析方式 | AI/手动切片、五种分析风格、切片成片导出 |
| 效率工具 | 单一任务的输入、预览和结果 | 批量改名、字幕、海报、图片视频均显示真实输入预览 |

## 6. 已冻结的对齐标准

1. 1440×900 和 1280×720 下，顶栏、三栏和底部任务区不可出现横向滚动条。
2. 两种尺寸下，视频预览始终有可见面积；竖屏视频完整显示且不被栏位裁切。
3. AI 页的无素材状态必须同时看见导入入口、预览占位和文案区域。
4. 右栏设置在两种尺寸下允许内部滚动，但不能盖住中栏预览或任务按钮。
5. 深色、浅色和跟随系统三种主题下，预览画布可保持黑色，画布外控件必须随主题变化。
