# 智剪 SmartCut：深色混剪工作台 UI 与文案改良方案

日期：2026-09-10。对象：电商短视频、自媒体批量剪辑用户。

结论：保留左侧素材、中间预览与文案、右侧参数、底部任务区。先修正文字与真实行为不一致的问题，再做分组、可读性与操作层级；不以大面积玻璃效果、更多卡片或更大的留白代替体验改善。

审查范围：本轮用户消息未附图片；依据运行中的视频混剪和 AI 工作台深色页面、1280×720 与 1440×900 窗口，以及文件夹设置、选材流程源码。展开文件夹参数、真实素材状态及云服务结果未完成本轮全量视觉验收，不能称为“所有页面已优化完成”。

实施状态：此前提交 e260921 仅含公共 CSS 微调及占位计算清理。本轮补正该 CSS 在窄窗口引起的任务栏换行问题。以下大部分为待实施方案，不冒充已上线功能。桌面开发版进程已启动。

## ① 问题清单

优先级：P1 会误导操作或产生错误预期；P2 影响找功能、读信息和操作效率。

| 编号 | 优先级 | 问题与证据 | 落地处理 |
| --- | --- | --- | --- |
| 01 | P1 | 未导入文件夹时，“文案模式/音频模式”看似可点，事件只遍历已有文件夹，空数组导致点击无效果。 | 保存独立的待导入模式；新导入文件夹继承选择，不再用空数组 every 判断默认模式。 |
| 02 | P1 | 普通/分类混剪指引中的“不再自动显示”没有状态绑定与持久化。 | 分模块保存偏好；勾选后再次进入和重启都不再自动弹出，仍可从“操作指引”打开。 |
| 03 | P1 | 普通混剪确认框把执行模式写死为“自定义素材规则”。 | 读取真正待提交的模式；展示文案条数、每文案版本数、最终条数、输出目录及删原片状态。 |
| 04 | P1 | “语速调整”绑定 App 的 playbackSpeed，而非 TTS 专用语速字段。 | 先核对请求和结果；若调视频速度就叫“视频速度”，要叫“配音语速”必须接入配音生成参数。 |
| 05 | P1 | “由文案/音频时间轴匹配”与普通混剪的按文件夹选材、叠加配音字幕流程不等价。 | 当前普通混剪明确写“按文件夹规则选材”；AI 逐句镜头匹配只在实际支持的工作区承诺。 |
| 06 | P1 | “顺序抽取”算法随版本偏移且从不断缩小的候选集合取模；不宜直接承诺严格按列表依次抽取。 | 先定义顺序基准、跨成片续取和循环规则，用 A/B/C/D 素材验证，再固化提示文案。 |
| 07 | P1 | “素材截取范围”像起止时间，但实现是最短/最长片段时长并随机选起点。 | 改成“每段截取时长”，标记“最短/最长”；0 的特殊含义显式呈现。 |
| 08 | P1 | “按文案分类”易被理解为 AI 分类素材，实际为导出文件夹组织方式。 | 放进“成片保存方式”，改“按文案分文件夹”；无文案时给出真实保存规则。 |
| 09 | P1 | “允许素材重复”未说明单条内部、跨条还是整个批次；当前去重集合在每条生成时重建。 | 文案标明“同一条成片内”；不同成片允许复用需额外说明，不能承诺批次完全不重复。 |
| 10 | P2 | 右侧“创建任务”和底部生成按钮并存，两组日志/结果入口并存，用户难以判断执行路径。 | 同一页面保留一个高强调主入口；两处入口统一调用确认流程，重复入口降低层级。 |
| 11 | P2 | 右侧高级字幕样式默认展开，零素材时占据大量空间；核心数量、输出目录不够突出。 | 常驻显示混剪规则、数量、比例和输出位置；配音/字幕/画面效果按启用状态展开。 |
| 12 | P2 | 主按钮灰置却缺少紧邻的可操作原因，底部“请先选择输出目录”不能直接定位设置。 | 显示下一项缺失条件及“选择输出文件夹”等可执行入口，主按钮名称保持稳定。 |
| 13 | P2 | “原视频音量”和配音区域的“原声音量”难区分；后者实际为配音时保留的源声。 | 分别明确作用条件，后者改“配音时保留原声”；不要误改成“配音音量”。 |
| 14 | P2 | “字体透明 100%”实际上表示完全不透明，与用户直觉相反。 | 改“字幕不透明度”；100% 完全显示，数值越小越透明。 |
| 15 | P2 | “已接入”是开发状态；“AI 成片/AI 智能混剪”“结果/结果0”等命名口径不一。 | 删除开发术语；工作区及结果入口使用统一名称，数量附在名称后。 |
| 16 | P2 | 预览把输出比例、填充、裁剪、文字挤在同一行，缺少组名；原素材预览容易被当成成片预览。 | 分“输出比例/背景填充/画面编辑”三组；预览明确标记素材或成片，不承诺全部效果实时预览。 |
| 17 | P2 | 字体和帮助文案偏小，右栏深灰控件难区分；高光、边框、阴影层层叠加，主次不清。 | 关键标签 12–13px、正文 13–14px，辅助信息至少 11–12px；减少高光，保留清晰焦点和选中边框。 |
| 18 | P2 | 进入模块先弹长篇指引，阻断老用户操作；已有“下次不再显示”尚无作用。 | 首次简短引导+可恢复详细指引，之后按偏好展示；把操作系统选择文件夹的说明移入帮助。 |
| 19 | P2 | 默认自定义模式，输出方式却为按文案分类；默认单文件夹抽 1 个素材，而混剪要求至少 2 个。 | 新任务默认值须与可提交条件协调，素材不足就就地说明，不覆盖已保存工程设置。 |
| 20 | P2 | 文字水印“添加文本”和字幕样式容易混淆；字体选择、字号、生成字幕的排列顺序倒置。 | “添加文字”注释为画面固定文字；“视频字幕”先启用，再显示字体、位置、颜色等样式。 |
| 21 | P2 | 普通导出结果只有文件列表，不能直接检查成片；日志缺少搜索与错误筛选。 | 共用现有媒体预览能力；单播放器按选中项加载，日志按实际记录筛选，错误同时有文字标记。 |
| 22 | P2 | 本轮 CSS 曾使1280宽任务栏额外换行。 | 已修正为单行弹性布局；后续还须用处理中、失败重试状态检查，不能仅以空状态判定全部通过。 |

## ② 文案修改对照表

核心操作采用“动作＋对象”，高级设置采用“参数名＋单位＋适用条件”。功能名称、结果状态、对象单位分别统一：素材文件用“个”，视频片段用“段”，成片用“条”，配音用“配音”，源音轨用“原声”。

| 原文 | 优化后 | 修改理由／必要条件 |
| --- | --- | --- |
| AI 成片 / AI智能混剪 | AI 智能混剪 | 工作区名称一致。 |
| 批量混剪（顶栏） | 批量混剪 | 保留行业常用词；页面内区分视频混剪与分类混剪。 |
| 导入文件夹 | 导入素材文件夹 | 首次操作明确对象；窄按钮可保留“导入文件夹”，组名说明素材。 |
| 暂无素材文件夹 | 先导入一组素材 | 空状态引导下一步。 |
| 文件夹是独立素材库，可分别配置混剪规则 | 每个文件夹可单独设置选材规则 | 去掉会与独立素材库功能混淆的说法。 |
| 使用指引 | 操作指引 | 统一帮助名称。 |
| 混剪输入 | 混剪方式 | 描述用户要做的选择。 |
| 自定义 | 按素材混剪 | “自定义”缺少与其他模式的差异信息。 |
| 文案模式 | 文案配音混剪 | 明确文案会生成配音，避免承诺普通混剪具备 AI 逐句匹配。 |
| 音频模式 | 已有配音混剪 | 明确以用户音频作为配音输入。 |
| 已接入 | 删除此标签 | 软件应呈现可用状态，不展示开发进度。 |
| 素材截取范围 | 每段截取时长：最短／最长（秒） | 实际控制随机片段长度，不是源视频起止位置。 |
| 使用素材数量 | 每条从本文件夹抽取（个） | 明确单条成片与当前文件夹范围。 |
| 混剪导出数量 | 本次生成（条） | 批次级数量，不应伪装成各文件夹可独立不一致的参数。 |
| 每个文案裂变数量 | 每条文案生成（条） | 主界面无需用户理解“裂变”，帮助内可保留“多版本”。 |
| 随机抽取 | 随机抽取 | 行业术语保留；补“随机选择素材，可能在不同成片中复用”。 |
| 顺序抽取 | 按列表顺序抽取 | 待修正并验证当前顺序算法后采用；不可先改字冒充行为。 |
| 允许素材重复 | 同一条成片内重复使用素材 | 清楚限定范围；注明不同成片仍可复用。 |
| 视频输出方式 | 成片保存方式 | 与分辨率、格式等输出规格分离。 |
| 按文案分类 | 按文案分文件夹 | 只描述保存位置，不暗示智能分类。 |
| 不分类 | 保存到同一文件夹 | 明确文件管理结果。 |
| 固定首素材 | 指定开头素材 | 文件固定与文件夹选取的行为需分别说明。 |
| 固定方式：默认／独立拼接 | 开头计入抽取数量／额外添加开头 | 当前实现差别正是开头是否占用数量。 |
| 原比例 | 跟随素材比例 | 加注多素材任务以哪条素材为基准，避免不明确承诺。 |
| 9:16 / 16:9 / 1:1 | 9:16 竖屏 / 16:9 横屏 / 1:1 方形 | 数字与常用场景对应。 |
| 适应填充 / 模糊填充 | 完整显示（黑边）/ 完整显示（模糊背景） | 以实际 contain/pad 行为为前提；不能称为裁切铺满。 |
| 视频裁剪 | 裁剪画面 | 动作与对象明确。 |
| 添加文本 | 添加文字 | 帮助注明“叠加在画面上的固定文字，不是语音字幕”。 |
| 选择素材后在此预览 | 在左侧选择素材，即可预览 | 明确操作位置；画面上方标“素材预览”。 |
| BGM音量 | 背景音乐音量 | 新手无需先认识缩写。 |
| 语音合成 | AI 配音 | 行业常用且更直接。 |
| 原声音量（配音区） | 配音时保留原声 | 必须保持绑定 ttsOriginalAudioVolume 的真实语义。 |
| 语速调整 | 视频速度，或接入真实TTS后称配音语速 | 不把视频变速伪装成配音参数。 |
| 文本/字幕样式 | 视频字幕 | 开关优先；启用后展示“字幕样式”。 |
| 字体透明 | 字幕不透明度 | 修正百分比方向歧义。 |
| 创建任务 / 提交任务 | 创建混剪任务 / 确认并开始 | 前者进入确认，后者才真正执行。 |
| 请先导入一组素材（按钮） | 主按钮保持“创建混剪任务”；旁边显示“请先导入素材” | 稳定按钮语义，缺失条件单独说明；可提供导入快捷入口。 |
| 结果 / 结果0 | 导出结果（0） | 与任务记录、素材结果明确区分。 |
| 打开位置 | 打开文件位置 | 明确打开文件管理器。 |
| 可浏览 · 处理需会员 | 可预览，开始生成需开通会员 | 只用于执行权限；API/TTS配置另行提示。 |
| 下次不再自动显示 | 下次不自动打开指引 | 必须实现保存偏好后交付。 |

建议就地帮助：

- 随机抽取：“每条视频按规则随机选材。不同成片可能用到相同素材，不保证内容完全不重复。”
- 顺序抽取：“按当前素材列表依次选取。”只在选材算法改正后显示；是否跨成片续取、末尾循环需产品规则明确。
- 按文案分文件夹：“同一条文案的多个成片保存到同一个子文件夹；不会自动给原素材分类。”
- 片段时长：“每次从源视频随机截取指定长度的片段。起点由程序选择。”
- 数量摘要：“3 条文案 × 每条 2 个版本 = 6 条成片”；必须读取最终任务计划，不能仅由输入框相乘后宣称成功。
- 智能切片：“按镜头变化切分全部素材（N 个）”。只处理选中素材时改为“按镜头变化切分所选素材（N 个）”。用户举出的“智能切片全部素材”不是本轮运行页面已确认的原文，此处为命名规范。

## ③ UI 改版方案

### 布局与分组

保持三栏与底部任务区，不更换导航架构。以下为建议布局，并非当前成品截图：

```text
顶部：返回首页 ｜ AI智能混剪 / 批量混剪 / 效率工具 ｜ 账号 / 帮助 / 任务队列
┌ 左侧：① 导入素材 ┬ 中间：③ 预览                   ┬ 右侧：② 混剪设置 ┐
│ 导入素材文件夹    │ 素材预览 / 成片预览（有结果才启用）│ 核心参数          │
│ 文件夹与素材数量  │ 输出比例 ｜ 背景 ｜ 裁剪 / 文字    │ 混剪方式、数量    │
│ 文件夹设置       │                                    │ 输出比例、目录    │
│ 缺失/异常素材提示 │          视频画面                  │ 配音与字幕        │
│                 │                                    │ 高级选项（收起）  │
│                 │ 文案/已有配音输入（按模式显示）       │ 当前设置摘要      │
└─────────────────┴────────────────────────────────────┴───────────────────┘
底部：状态与下一步提示 ｜ 任务日志 / 导出结果 ｜ ④ 创建混剪任务
```

“预览”必须标明是原素材、支持的效果预览还是已生成成片；随机选材未完成前不使用“最终成片预览”名称。比例变化只改变画面内容和比例框，不改变播放器外壳。文案输入不得挤没视频预览；右栏单独滚动，任务主操作固定可见。

建议尺寸：顶栏约48px，栏间距10px，左右外边距12px；左栏约280–300px，右栏约280–300px，中间弹性。1280宽下中栏至少约600px，1440宽下增加预览宽度。具体值以现有布局和真实素材验证确定；不机械叠加导致1280宽横向滚动的最小宽度。

核心参数：输入素材、选材方式、抽取数量、生成条数、输出比例与文件夹。高级参数：重复规则、开头素材、片段时长、背景音乐细项、字幕字体细项、水印、调色、动态缩放。高级项收起后仍显示已启用数量/摘要，不清空设置。

### 深色视觉

| 用途 | 建议色值 | 使用规则 |
| --- | --- | --- |
| 页面底色 | #12161B | 大面积背景，减少渐变 |
| 主面板 | #1B2129 | 左右面板与中栏承载区 |
| 输入框 | #141A21 | 必须有边框，避免与面板融为一体 |
| 边框 | #3B4653 | 一层清晰边界，减少嵌套亮边 |
| 主要文字 | #EDF2F7 | 标题、已填写内容 |
| 辅助文字 | #AAB5C2 | 帮助说明、次要信息 |
| 强调色 | #55CBB2 | 主操作和选中态；按钮文字用 #10251F |
| 错误 | #FF9B9B | 配文字说明，不仅红框 |
| 提醒 | #EAC77A | 参数冲突、会员门槛等必要提示 |

色值为建议设计令牌，实施时须覆盖实际计算色并测对比度。正常文字目标4.5:1；不重置用户已保存主题，也不移除原有主题选项。本方案只调整深色版本，其他主题做回归检查。

### 控件

- 主按钮高36–40px；普通按钮32–36px；图标按钮至少32px且有中文名称或悬停说明。
- 页面/区域标题16–18px、控件标签12–13px、正文13–14px、辅助文字11–12px；避免任务状态、文件名、参数标签继续使用9–10px。
- 输入框右侧显示单位；最短/最长分别标记；同一类数值右对齐，进度和计数使用等宽数字。
- 圆角统一6–8px；常规分组优先用标题与间距，少套卡片。
- 主按钮仅一处高强调；“清理临时文件”移至维护菜单，保留原功能，远离创建任务按钮。
- 错误正文允许换行并完整展开；路径单行省略，但悬停可查看完整路径，复制/打开操作独立。
- 12个颜色编号应改为颜色名称和十六进制值；选中加勾选符号，不能只靠颜色区分。

## ④ 交互细节与验收

### 推荐默认值

针对新建电商竖屏任务：9:16，先生成1条，源素材保留；背景音乐、水印和重度效果默认关闭。字幕在文案/配音模式下按用户实际选择启用。已有工程恢复原设置，不强制改9:16或深色。

“同条内不重复”适合作为新任务推荐值，但要联动素材不足校验；不够时解释还差多少素材，不自动打开重复。普通素材模式默认保存同一输出文件夹；文案模式可推荐按文案分文件夹。先明确业务规则并做参数测试，再修改默认值。

### 交互细节

1. 未导入也能选混剪方式和写文案；导入后继承。切换模式保留输入，避免误丢文案。
2. 选择“已有配音”后直接出现“选择配音文件 → 识别字幕 → 编辑识别结果”，显示音频文件名、时长与失败原因，不在纯说明里承诺自动完成。
3. 创建任务前就地提示第一项缺失；素材不足、目录不可写、配音未配置分别给修复入口。不要用一个“未准备好”覆盖所有问题。
4. 任务确认显示真正执行参数：条数、模式、预计处理范围、输出目录、是否保留源素材。确认与执行使用同一份冻结计划。
5. “应用到全部文件夹”说明覆盖哪些参数，展示目标数量；保留功能，不增加每次都出现的多余确认。
6. 取消后显示“正在停止处理”，结束后区分成功、失败、取消数量；失败重试只重做失败项。
7. 设置弹窗支持Esc关闭、Tab循环、打开后焦点进入、关闭后焦点回到触发按钮；主操作不能被背景按钮截获。
8. 结果抽屉单播放器切换成片，避免同时加载几十个视频；文件被移动时保留结果记录并解释无法播放。
9. 日志支持搜索和只看错误，显示实际记录数量；显示“没有匹配记录”与“尚无日志”两种不同空状态。
