# 10_开发者验收清单

## 用途

本文件用于每次开发或修复后做固定自检。

原则：
1. 先验证主链路。
2. 再验证本次新增功能。
3. 最后验证旧功能没有被破坏。
4. 不通过就不要继续加新功能。
