# 10_开发者验收清单

## 用途

本文件用于每次开发或修复后做固定自检。

原则：
1. 先验证主链路。
2. 再验证本次新增功能。
3. 最后验证旧功能没有被破坏。
4. 不通过就不要继续加新功能。

## 一、启动检查

- [ ] `corepack pnpm build` 通过。
- [ ] `cargo check` 通过。
- [ ] 软件可以正常启动。
- [ ] 首页可以进入工作台。
- [ ] FFmpeg / FFprobe 检测正常。

## 二、基础素材检查

- [ ] 可以导入单个视频。
- [ ] 可以导入文件夹。
- [ ] 非视频文件不会进入素材列表。
- [ ] 素材列表显示文件名。
- [ ] 点击素材后可以预览。
- [ ] 视频播放、暂停、进度条正常。

## 三、基础导出检查

- [ ] 可以选择输出目录。
- [ ] 基础导出可以生成 mp4。
- [ ] 导出结果会进入导出结果列表。
- [ ] 可以打开输出目录。
- [ ] 可以打开单个导出结果所在位置。

## 四、切片和随机混剪检查

- [ ] 固定时长切片可以生成片段。
- [ ] 片段列表显示正常。
- [ ] 随机抽取可以按数量抽出片段。
- [ ] 拼接抽中片段可以生成 mp4。
- [ ] 批量生成可以生成多条 mp4。
- [ ] 任务日志能看到关键步骤。

## 五、画布和视频效果检查

- [ ] 原画模式保持原始比例。
- [ ] 9:16 竖屏画布正常。
- [ ] 1:1 方屏画布正常。
- [ ] 16:9 横屏画布正常。
- [ ] 黑边背景正常。
- [ ] 模糊背景正常。
- [ ] 水平镜像正常。
- [ ] 垂直镜像正常。
- [ ] 旋转 90 度 / 180 度正常。
- [ ] 亮度、对比度、饱和度调整正常。
- [ ] 轻微缩放正常。
- [ ] 变速 0.5x 到 2.0x 正常。

## 六、平滑混剪检查

- [ ] 关闭平滑混剪时，拼接和批量生成仍正常。
- [ ] 开启平滑混剪时，片段切换有淡入淡出效果。
- [ ] 小于 1.5 秒的片段会被过滤。
- [ ] 任务日志能显示过滤情况。
- [ ] 平滑混剪可以和画布比例一起使用。
- [ ] 平滑混剪可以和基础视频效果一起使用。

## 七、画中画检查

- [ ] 不开启画中画时，原有混剪链路正常。
- [ ] 可以选择视频作为画中画素材。
- [ ] 可以选择图片作为画中画素材。
- [ ] 左上、右上、左下、右下、居中位置正常。
- [ ] 大小比例生效。
- [ ] 透明度生效。
- [ ] 边距生效。
- [ ] 画中画可以和 16:9 模糊背景一起使用。
- [ ] 画中画可以和平滑混剪、基础视频效果一起使用。

## 八、封面帧和片段预览检查

- [ ] 导入视频后，素材卡片出现封面图。
- [ ] 点击素材后，中间信息区显示当前封面帧。
- [ ] 切片后，片段列表出现预览图。
- [ ] 随机抽取后，已抽取片段继续显示预览图。
- [ ] 可以输入秒数并设为封面帧。
- [ ] 抽帧失败不影响切片、混剪和导出主链路。

## 九、分类混剪检查

状态：
V0.3.6 已完成人工验收。

- [ ] 切片后可以给片段选择分类。
- [ ] 支持开头钩子、产品展示、使用过程、细节特写、效果展示、结尾引导。
- [ ] 分类信息不会因为切换素材或抽取片段丢失。
- [ ] 分类混剪按固定顺序抽取片段。
- [ ] 空分类会自动跳过。
- [ ] 至少两个分类有片段时可以导出 mp4。
- [ ] 导出结果进入导出结果列表。
- [ ] 任务日志能显示每个分类抽中的片段。
- [ ] 原有随机混剪不受影响。

## 十、音频与 BGM 检查

状态：
V0.4.1 / V0.4.2 已开发，等待联合人工验收。

- [ ] 不开启 BGM 时，原有混剪导出正常。
- [ ] 可以选择本地音频文件作为 BGM。
- [ ] 开启 BGM 后，导出视频可以听到背景音乐。
- [ ] 原视频音量设置生效。
- [ ] BGM 音量设置生效。
- [ ] BGM 比视频短时不会中途静音。
- [ ] BGM 比视频长时不会让导出视频变长。
- [ ] BGM 淡入秒数默认为 0.5 秒。
- [ ] BGM 淡出秒数默认为 0.5 秒。
- [ ] BGM 开头不会突然进入。
- [ ] BGM 结尾不会突然停止。
- [ ] 淡入 / 淡出秒数设为 0 时，不做渐变。
- [ ] 淡入 / 淡出秒数只能在 0 到 10 秒之间。
- [ ] 分类混剪可以带 BGM 导出。
- [ ] 批量生成可以带 BGM 导出。
- [ ] 任务日志能显示 BGM 是否启用。
