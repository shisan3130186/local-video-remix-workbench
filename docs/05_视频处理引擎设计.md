# 视频处理引擎设计

> 文档定位：下方版本规划保留为历史设计基线。当前 AI 智能混剪仍严格复用本文件定义的 VideoEngine 边界，AI 只负责画面理解和分镜规划，不在前端直接拼接 FFmpeg 命令。

## 目标

所有视频处理统一通过 VideoEngine 调用，禁止页面组件直接拼接 FFmpeg 命令。

VideoEngine 是本项目最核心的技术边界。页面组件只传入用户选择和参数，不关心 FFmpeg 命令怎么拼。

## 模块

### VideoProbeService

负责：
- 检测 ffmpeg
- 检测 ffprobe
- 读取视频时长
- 读取分辨率
- 读取帧率
- 读取音频信息

V0.1 必须做：

1. 检测 ffmpeg 是否存在。
2. 检测 ffprobe 是否存在。
3. 返回 ffmpeg 版本号。
4. 返回 ffprobe 版本号。
5. 读取视频基础信息。

暂时不做：

1. 画面内容识别。
2. 字幕识别。
3. 镜头识别。

### VideoImportService

负责：
- 单文件导入
- 文件夹导入
- 视频格式过滤
- 文件路径管理

V0.1 必须做：

1. 单视频导入。
2. 文件夹导入。
3. 过滤非视频文件。
4. 保留原始文件路径。

暂时不做：

1. 素材云同步。
2. 智能去重。
3. 自动分类。

### VideoRenderService

负责：
- 基础导出
- 格式转换
- 分辨率处理
- 错误捕获

V0.1 必须做：

1. 把一个导入视频导出成新的 mp4。
2. 支持选择输出目录。
3. 返回导出结果。
4. 捕获失败原因。

暂时不做：

1. 复杂滤镜。
2. 多版本批量导出。
3. GPU 加速策略。

### VideoSplitService

负责：
- 固定时长切片
- 后续场景切割

V0.1 不做。

计划：

1. V0.2 做固定时长切片。
2. V0.2 做随机片段抽取。
3. V0.6 再考虑场景识别切割。

当前补充规则：切片开始前由Rust确认输出目录真实存在；前端路径文字不为空不能代替文件系统检查。原始素材封面使用固定320×240完整画面模式，AI分析预览图保持源比例。

### VideoMixService

负责：
- 随机抽取片段
- 拼接片段
- 批量生成

V0.1 不做。

计划：

1. V0.2 做基础随机混剪。
2. V0.4 做分类混剪。
3. V0.6 再考虑 AI 辅助选片。

## 推荐返回格式

所有 VideoEngine 方法建议返回结构化结果，不要只返回字符串。

示例：

```text
成功结果：
{
  success: true,
  data: 具体结果,
  message: "操作成功"
}

失败结果：
{
  success: false,
  errorCode: "错误代码",
  message: "给用户看的错误说明",
  detail: "给开发者看的详细错误"
}
```

## FFmpeg 调用规则

必须遵守：

1. 所有 FFmpeg / FFprobe 调用集中在 VideoEngine。
2. 页面组件不能拼接命令。
3. Service 层不能散写重复命令。
4. 命令参数必须来自明确的结构化参数。
5. 文件路径要支持中文和空格。
6. 错误信息要能返回给任务日志。

## V0.1 VideoEngine 最小能力

V0.1 只需要支持：

1. 检测 ffmpeg。
2. 检测 ffprobe。
3. 读取视频基础信息。
4. 基础导出。
5. 返回进度和错误信息。

## 后续扩展能力

### TTS第一阶段边界

当前TTS第一阶段只由Rust网络模块生成本地MP3，不修改视频文件，因此不进入VideoEngine混音流程。后续实现“配音加入视频”时，原声音量调整、配音轨道、BGM混音、镜头时长适配和最终编码必须统一放入VideoEngine，前端不得拼接FFmpeg命令。

### TTS第二阶段边界

TTS第二阶段新增独立 `narrated_mix` 模块。每个AI分镜输入主视频、备选视频和临时配音路径，VideoEngine读取真实配音时长：画面较长时裁短，主画面较短时先换用可安全适配的较长备选画面，再允许最多8%轻微减速和约0.8秒尾帧补齐。超过安全范围时直接报错，禁止连续数秒冻结最后一帧。原片段声音默认关闭；用户主动开启后，VideoEngine会检测实际选中画面的音轨、按相同轻微速度和指定音量混入，无音轨时自动退回纯AI配音。处理后的分镜继续交给现有混剪引擎，因此画布、效果、画中画、平滑混剪和BGM继续生效。

当前限制：
1. 配音视频只支持1.0x速度。
2. 原片段声音默认关闭，可选0%～100%混合，默认15%；不做人声与BGM分离。
3. 自动字幕只支持分镜内自然短句，不做逐字时间轴。
4. 不做声音克隆和批量多音色。

### 自动字幕第一阶段边界

自动字幕只接入逐句AI配音视频。`subtitle`模块根据分镜文字和配音时长生成ASS文件，优先按标点拆成自然短句，没有标点的长文案按可读长度拆分，再按有效字符数分配显示时间。支持顶部、中间、底部位置和小、标准、大字号。字幕在临时配音分镜阶段烧录，因此后续画布、特效、画中画、平滑混剪、原声和BGM继续走原有VideoEngine链路。

当前限制：
1. 只生成分镜内短句字幕，不做逐字时间轴或词级精确对齐。
2. 不识别原视频语音，不调用ASR。
3. 默认使用微软雅黑；FFmpeg必须包含libass的 `ass` 滤镜。
4. 不支持复杂动画、颜色编辑、描边编辑或字幕模板。
