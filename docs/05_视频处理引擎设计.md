# 视频处理引擎设计

## 目标

所有视频处理统一通过 VideoEngine 调用，禁止页面组件直接拼接 FFmpeg 命令。

VideoEngine 是本项目最核心的技术边界。页面组件只传入用户选择和参数，不关心 FFmpeg 命令怎么拼。

## 模块

### VideoProbeService

负责：
- 检测 ffmpeg
- 检测 ffprobe
- 读取视频时长
- 读取分辨率
- 读取帧率
- 读取音频信息

V0.1 必须做：

1. 检测 ffmpeg 是否存在。
2. 检测 ffprobe 是否存在。
3. 返回 ffmpeg 版本号。
4. 返回 ffprobe 版本号。
5. 读取视频基础信息。

暂时不做：

1. 画面内容识别。
2. 字幕识别。
3. 镜头识别。

### VideoImportService

负责：
- 单文件导入
- 文件夹导入
- 视频格式过滤
- 文件路径管理

V0.1 必须做：

1. 单视频导入。
2. 文件夹导入。
3. 过滤非视频文件。
4. 保留原始文件路径。

暂时不做：

1. 素材云同步。
2. 智能去重。
3. 自动分类。

### VideoRenderService

负责：
- 基础导出
- 格式转换
- 分辨率处理
- 错误捕获

V0.1 必须做：

1. 把一个导入视频导出成新的 mp4。
2. 支持选择输出目录。
3. 返回导出结果。
4. 捕获失败原因。

暂时不做：

1. 复杂滤镜。
2. 多版本批量导出。
3. GPU 加速策略。

### VideoSplitService

负责：
- 固定时长切片
- 后续场景切割

V0.1 不做。

计划：

1. V0.2 做固定时长切片。
2. V0.2 做随机片段抽取。
3. V0.6 再考虑场景识别切割。

### VideoMixService

负责：
- 随机抽取片段
- 拼接片段
- 批量生成

V0.1 不做。

计划：

1. V0.2 做基础随机混剪。
2. V0.4 做分类混剪。
3. V0.6 再考虑 AI 辅助选片。

## 推荐返回格式

所有 VideoEngine 方法建议返回结构化结果，不要只返回字符串。

示例：

```text
成功结果：
{
  success: true,
  data: 具体结果,
  message: "操作成功"
}

失败结果：
{
  success: false,
  errorCode: "错误代码",
  message: "给用户看的错误说明",
  detail: "给开发者看的详细错误"
}
```

## FFmpeg 调用规则

必须遵守：

1. 所有 FFmpeg / FFprobe 调用集中在 VideoEngine。
2. 页面组件不能拼接命令。
3. Service 层不能散写重复命令。
4. 命令参数必须来自明确的结构化参数。
5. 文件路径要支持中文和空格。
6. 错误信息要能返回给任务日志。

## V0.1 VideoEngine 最小能力

V0.1 只需要支持：

1. 检测 ffmpeg。
2. 检测 ffprobe。
3. 读取视频基础信息。
4. 基础导出。
5. 返回进度和错误信息。

## 后续扩展能力

V0.2：

1. 固定时长切片。
2. 随机片段抽取。
3. 片段拼接。
4. 批量导出。
5. 镜像、变速、裁剪比例。

V0.3：

1. 平滑混剪。
2. 基础视频效果。
3. 画中画。
4. 封面帧 / 片段预览。
5. 分类混剪。

V0.4：

1. 本地 BGM。
2. 原视频音量和 BGM 音量。
3. BGM 自动适配导出视频长度。
4. 拼接抽中片段、分类混剪和批量生成接入 BGM。

V0.6：

1. ASR 字幕识别。
2. OCR 画面文字识别。
3. 内容提炼。
4. AI 辅助选片。
