# 智剪 SmartCut 会员系统与卡密管理说明

## 一、当前范围

V0.5.0已经实现：

1. 邮箱注册、登录和退出。
2. 账号会员状态和有效期。
3. 一次性兑换码充值，会员天数自动叠加。
4. 修改密码并使其他设备旧会话失效。
5. 同一账号换电脑登录恢复会员。
6. 最多72小时离线签名宽限，且不能超过会员到期时间。
7. 管理员本机可视化卡密生成、停用和恢复。

暂未实现：邮箱找回密码、短信登录、支付接口、多人管理员后台、管理员操作审计和设备数量限制。

## 二、系统结构

```text
智剪Vue个人中心
    ↓ Tauri命令
Rust会员模块
    ↓ HTTPS
腾讯云开发CloudBase HTTP云函数
    ↓
CloudBase文档数据库
```

正式环境ID：`smartcut-membership-d8bfdff54769`。

正式桌面端只在编译时写入CloudBase地址和ECDSA公开验签公钥。服务端私钥和管理员令牌不会进入普通用户软件。

## 三、服务端接口

- `GET /health`：健康检查。
- `POST /v1/auth/register`：注册并返回登录会话。
- `POST /v1/auth/login`：登录。
- `POST /v1/auth/logout`：退出当前会话。
- `GET /v1/account/me`：刷新账号与会员状态。
- `POST /v1/account/redeem`：兑换一次性卡密。
- `POST /v1/account/change-password`：修改密码并使其他设备旧会话失效。
- `GET /v1/admin/codes`：管理员查看卡密。
- `POST /v1/admin/codes`：管理员生成卡密。
- `PATCH /v1/admin/codes/:id`：管理员停用或恢复未兑换卡密。

## 四、数据库集合

- `users`：邮箱、昵称、密码哈希、随机盐、账号状态和会话版本。
- `sessions`：会话令牌哈希、用户ID、有效期和最后使用时间。
- `memberships`：账号会员状态、到期时间和更新时间。
- `redemption_codes`：兑换码哈希、会员天数、状态、备注和兑换账号。
- `membership_events`：注册、登录、兑换、改密和退出的基础事件记录。

密码使用PBKDF2-SHA256独立随机盐。完整会话令牌、明文密码和明文兑换码不保存在数据库。

## 五、桌面端安全

1. 服务端使用ECDSA P-256私钥签名账号和会员状态。
2. 桌面端只内置公开验签公钥，无法伪造会员签名。
3. Windows使用当前用户数据保护机制加密保存会话和签名缓存。
4. 登录被服务端明确拒绝时会清理本机会话；只有网络或临时服务故障可以使用有效离线缓存。
5. 离线宽限最多72小时，并受真实会员到期时间限制。

## 六、管理员怎么生成卡密

最简单的方法：双击项目根目录`启动智剪卡密管理器.vbs`。

管理器支持：

- 1天、7天、30天、90天和365天快捷时长。
- 1～3650天自定义会员时长。
- 内部备注。
- 生成后自动复制。
- 全部、未使用、已使用和已停用筛选。
- 停用未使用卡密和恢复已停用卡密。

管理器只供管理员本机使用，不进入普通用户安装包，也不上传到CloudBase云函数代码包。

## 七、密钥和部署

本机加密文件：

- `.cloudbase-signing-private.local.txt`：Windows当前用户加密的签名私钥。
- `.cloudbase-admin-token.local.txt`：Windows当前用户加密的管理员令牌。
- `.cloudbase-signing-public.local.txt`：公开验签公钥。

以上`.local.txt`文件均被Git忽略；管理器和本地密钥目录也被CloudBase部署规则排除。

重新配置云端密钥：

```powershell
services\membership-api\scripts\configure-cloudbase-secrets.ps1
```

部署CloudBase函数：

```powershell
cd services\membership-api
corepack pnpm run deploy:cloudbase
```

## 九、常见问题

### 管理器打不开

确认使用项目根目录`启动智剪卡密管理器.vbs`，并确认管理员加密令牌文件存在。管理器脚本包含中文时必须保存为带BOM的UTF-8。

### 兑换码无法使用

确认兑换码以`SCUT-`开头、没有输错字符、尚未兑换且未被管理员停用。每个兑换码只能使用一次。

### 国内接口无法连接

先访问CloudBase健康检查并确认环境状态正常；不要把Cloudflare `workers.dev`地址写入国内正式安装包。
