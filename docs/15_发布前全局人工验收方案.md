# 发布前全局人工验收方案

可交互填写版：`15_发布前全局人工验收方案.html`。每项可标记通过或失败，填写问题和截图路径后导出 HTML 报告发回开发者。

适用版本：Git `f29d8e9` 之后的本地测试版本。
目标：由产品负责人完整走查全部公开功能，确认“界面可用、参数真实生效、结果文件可播放、失败可恢复”后，再制作外部用户测试包。

## 一、验收结论规则

- `通过`：操作完成，界面反馈正确，输出文件存在且可播放，修改的参数能在结果中观察到。
- `失败`：崩溃、卡死、无法继续、生成文件缺失/损坏、参数未生效、错误提示不清楚、原文件被意外覆盖。
- `阻断问题（P0）`：软件无法启动、无法登录/激活、无法导入、无法导出、导出损坏、原文件丢失、数据或密钥泄露。
- `重要问题（P1）`：关键功能结果不对、任务不能重试、主题导致控件不可读、预览明显错误。

发布门槛：所有 P0 和 P1 均为零；下面标注“必须真实导出”的项目全部通过；测试记录、截图和结果文件完整保存后，才可以打包发给外部用户。

## 五、视频生产链路

以下每一项都需要实际导出 MP4 并播放。播放时检查：有画面、有声音或符合关闭原声的设置、时长合理、比例正确、文件在选定目录、原视频仍存在。

### 5.1 AI 智能混剪

1. 导入横屏和竖屏素材，确认原视频预览完整显示；切换原比例、9:16、16:9、1:1 和填充方式，播放器外壳不被挤压。
2. 分别测试本地匹配与云端匹配；输入短文案和长文案，确认分镜、素材匹配、候选画面和任务状态真实更新。
3. 开启和关闭 AI 配音、原声、字幕；分别修改音色、字幕位置、字号、颜色、透明度，至少导出两条对比视频。
4. 在裁剪和添加文本模式下拖动、缩放并关闭工具，确认视频本体不被意外缩放，文字位置进入导出结果。
5. 让一个任务失败或取消，确认失败条目可重试且成功条目不重复生成。

### 5.2 视频效果处理

1. 导入横竖屏视频，确认预览、封面、输出规格和基础参数均可见。
2. 各导出一条对比视频：镜像/旋转、变速、HSL 调色、动态缩放、画布比例、裁剪、文本。
3. 测试 BGM：关闭、开启、音量变化、淡入淡出、循环和不循环；确认成片声音与设置一致。
4. 测试画中画：主视频模式、外部素材模式、大小、位置、透明度；确认真实叠加。
5. 测试入场效果、帧操作、像素融合、封面和批量输出；确认每项不是只高亮界面。

### 5.3 水印与去水印

1. 添加文字水印、图片水印、图片/视频贴画，分别调整位置、大小、透明度和轨迹后导出。
2. 对有水印素材点击“自动检测常见水印区域”，确认候选框出现且可拖动微调。
3. 分别选择融合修复、区域模糊、马赛克、色块遮盖并导出，确认四种结果画面有明确差异。
4. 无水印素材也执行自动检测，确认不会产生越界框、崩溃或假成功。

### 5.4 普通视频混剪与分类混剪

1. 普通混剪：导入多条视频，测试随机抽取、重复规则、批量数量、字幕、BGM、画中画和输出命名。
2. 分类混剪：创建多个分类文件夹，设置分类顺序和每类规则，确认每条成片按照分类顺序选取片段。
3. 分别测试单条失败、取消、重试、打开结果目录和重新导入后状态清理。
4. 检查删除原文件选项：未明确开启时源文件绝不删除；开启时先用可丢弃复制件验证。

### 5.5 信息流带货成片

1. 在珍珠雾白主题下进入页面，确认整个工作区是浅色，只有视频预览画布为黑色；切到夜航墨色再切回白色。
2. 填写商品名称、目标用户、痛点、卖点、结尾引导；导入至少三条视频，选择输出目录，完成切片和分类修正。
3. 分别选择“问题→解决方案、结果先行、人物口播”，各导出三条成片；确认三条镜头顺序不同、为 9:16、商品文案进入字幕。
4. 关闭字幕再导出，确认结果没有烧录字幕；重新开启字幕后字幕恢复。
5. 制造一个版本失败，确认“重试失败版本”只处理失败版本；结果卡可预览真实视频并打开目录。

## 六、效率工具与辅助功能

| 功能 | 必做操作 | 通过标准 |
| --- | --- | --- |
| 文案改写 | 输入单条和多条文案，切换语气、长度与提示词 | 返回条数正确，复制/保存结果可用，失败提示不丢原文。 |
| 视频内容提炼 | 导入长视频并完成切片、内容分析、分类与精华成片 | 分析结果可见，分类可改，精华成片真实导出。 |
| 批量改名 | 用复制件测试前缀、后缀、序号、预览和确认 | 不覆盖已有文件；失败时说明冲突原因。 |
| 字幕识别 | 用带人声视频执行 ASR，修改字幕后导出 | 文本、时间轴和最终烧录字幕一致。 |
| 大字报 | 输入文字、调整样式并导出 | 图片或视频文件存在，所选文字与样式可见。 |
| 图片转视频 | 导入图片，设置比例、时长、动效和配乐 | 生成视频可播放，画面比例与时长符合设置。 |
| 诊断与日志 | 打开诊断、查看任务日志、导出或复制信息 | 不显示密钥、密码、卡密或完整会话。 |

## 七、发布前稳定性回归

1. 连续完成三类任务后退出软件，再次启动，确认不会自动误报任务成功或损坏项目状态。
2. 连续导入/导出 10 次，观察内存、界面卡顿和结果目录；不允许崩溃或出现重复/空文件。
3. 断网时触发 AI/TTS/ASR，确认错误可理解且本地素材和文案保留；网络恢复后可以重试。
4. 用不支持格式、空文件、超短视频、超长文件名、输出目录无权限分别测试一次，确认有明确失败信息。
5. 在全流程结束后检查测试结果目录：每一项有截图、输入说明、输出文件和结论；没有把密钥、账号信息或大体积测试素材提交进项目。
