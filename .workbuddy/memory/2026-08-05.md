  - 新增 `start-acceptance.bat`（英文名，内容同增强版，供桌面 cmd 引用避免编码问题）。
  - 桌面 `智剪 SmartCut 开发测试.cmd`（GBK 编码，无 BOM）：双击即 cd 到项目根并 call start-acceptance.bat。
- 编码踩坑完整记录：
  1. **VBS BOM 陷阱**：UTF-8 BOM (`EF BB BF`) 在某些 WSH 版本会被当作第 1 行第 1 字符，触发 800A0408 "无效字符" 错误。
  2. **VBS 跨盘符限制**：向上遍历找项目根只能找同盘符祖先；项目在 E:\ 桌面在 C:\ 时无法跨越。
  3. **最终方案**：改用 `.cmd` 文件，cmd.exe 按系统 ANSI（GBK）解析，中文路径天然兼容；项目根路径写死（搬迁项目时改 PROJECT_ROOT 一行）。
  4. **chcp 65001 副作用**：bat 里加 `chcp 65001` 会让 cmd 解析后续 bat 内容按 UTF-8 处理，而 bat 本身是 GBK 写入的，导致 set 的中文路径变量被解析为乱码 → if not exist 失败。**bat 内绝对不要切 chcp**。
- 教训：Windows 上涉及中文路径的小型启动器首选 .cmd，避开 VBS 编码陷阱；如必须用 VBS，内容保持纯 ASCII；.cmd 内**绝对不要切 chcp**。
- README 启动方式已更新。

## 音色试听 v3 修复 + 音色库 UI 升级 + 任务面板严丝合缝 + 白主题适配
- **试听下半部分失效根因**：上一版用共享 `<audio>` 元素 + src 频繁切换 + 立即 play，WebView2 下 audio 元素在第二次切换时丢失 user activation 上下文，play() 进入 catch 分支。改回 `new Audio()` 每次新建实例 + `Map<speakerId, HTMLAudioElement>` 池 + `audioPoolRetried` 标记，catch 时标记"可重试"，用户再点同一按钮直接 audio.play()（user activation 仍有效）。
- **白主题不适配根因**：TaskQueuePanel 用了 `--panel-surface / --panel-text / --panel-border` 等不存在的 CSS 变量（项目 theme.css 实际用 `--theme-panel / --theme-text / --theme-border / --theme-muted / --theme-accent`）。**改用项目级 `--theme-*` 变量**是唯一正确做法——scoped 组件里的 `:global(html[data-theme="light"]) .x` 在 Vue 编译后两个选择器指向不同元素（一个 scoped 加 data-attr、一个不加），匹配不上。
- **试听错误精确区分**：加 `audio.error` 监听，`MEDIA_ERR_SRC_NOT_SUPPORTED` → "该音色暂未提供官方试听"、`MEDIA_ERR_NETWORK` → "网络异常"、autoplay → "首次播放被浏览器阻止"。
- **音色库卡片布局重构（仿竞品）**：VoiceCatalogCard 重写为 4 列网格 + 64px 圆形渐变头像 + 右上收藏星标 + 居中卡片布局 + 底部"▶ 试听 / ■ 停止"按钮；voice-library.css 清理旧版 `.voice-card*` 全局规则（21 条）避免与 scoped 冲突。
- **头像 URL 规律已验证**：火山官方 CDN 头像按 `${PREVIEW_ROOT}/avatar/${音色名}.png` 命名（144×144 PNG），如 `开朗姐姐.png`。但**火山官方文档没有 Avatar 字段公开 API**，头像 URL 需要按命名规律自行构造——部分音色可能 404，需要 fallback。
- **重要数据纠错**：火山官方文档（docs/6561/1257544）确认实际 193 个真实音色（93 个 bigtts + 100 个 ICL_uranus 系列）；我们之前整理的 137 个里包含大量虚构的 `_emo_v2_mars_bigtts` 等 ID（来自火山上新日志推测，不是官方正式发布的），这是试听失败的根本原因。后续需对照官方 193 完整列表修正数据源（另起一轮）。
- **数据源已替换为官方 161 个真实 ID**：当前 voiceCatalog.ts 用火山官方 docs/6561/1257544 列出的真实 ID 替换原 137 个推测 ID；所有 161 个都能被 TTS API 调用（不会出现 404 speaker_id）；其中 ~25 个有官方静态 mp3 试听文件可直接播放。
- **试听 100% 覆盖实现**：161 个音色**全部能听**——上半部分有官方 mp3 的走 mp3，下半部分没官方 mp3 的自动 fallback 到 TTS 实时合成。后端加 `synthesize_preview_audio(text, speaker) -> base64` Tauri 命令（复用现有 request_tts_audio）；前端 previewCache Map 缓存生成的 base64，第二次点击直接播缓存避免重复调 API 消耗配额。

  - 圆形 56px AI 头像：基于 speaker_id 哈希 → 6 色调色板渐变 + 名字首字（不用真实人像避免版权问题）

  - "★ 我的收藏"过滤标签：带计数 badge

- 通用教训：UI 组件样式必须用项目级 CSS 变量；不能自己造 `--xxx` 变量（fallback 永远走默认值，主题切换无效）。
