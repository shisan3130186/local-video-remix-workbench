# 智剪卡密管理器

这是只给软件管理员使用的本机工具，不会进入普通用户安装包。

## 使用方法

1. 双击项目根目录的`启动智剪卡密管理器.vbs`。
2. 选择1天、7天、30天、90天、365天，或手动填写会员天数。
3. 填写备注，点击“生成并复制兑换码”。
4. 兑换码会自动复制，可以直接发送给用户。
5. 右侧列表可以查看未使用、已使用和已停用的兑换码。
6. 未使用的兑换码可以停用；已停用的兑换码可以恢复。

## 安全说明

- 管理器只读取Windows当前用户加密保存的管理员令牌。
- 不会在代码、界面或日志中显示管理员令牌。
- 不要把`.cloudbase-admin-token.local.txt`发送给任何人。
- 每个兑换码只能使用一次；兑换后会员天数会叠加到用户账号。
