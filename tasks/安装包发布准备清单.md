# Windows 安装包发布准备清单

## A. 内部测试包

- [x] Windows 发布版程序可以编译。
- [x] NSIS 安装器可以生成。
- [x] 安装包已经内置 FFmpeg / FFprobe。
- [x] AI/TTS/ASR可以在软件内安全配置，不依赖终端环境变量。
- [x] 安装后完成基础导入和主要流程人工验收。
- [ ] 卸载后程序文件可以正常清理，用户主动选择的素材和成片不能被删除。

## B. 发给外部普通用户前

- [x] 安装包内置合法来源的 FFmpeg / FFprobe，并附许可证和来源说明。
- [x] 不要求普通用户打开 PowerShell 配置环境变量。
- [x] AI Key采用用户自己的Key并由Windows当前用户加密保存。
- [x] 不把开发者公共 API Key 写进前端、安装包或普通配置文件。
- [ ] 收窄本地文件访问权限，避免默认允许整个电脑目录。
- [x] 准备正式应用图标、版本说明和隐私说明。
- [ ] 公开商业发布前补充正式用户协议。
- [ ] 使用代码签名证书，减少 Windows SmartScreen 的未知发布者警告。
- [ ] 在一台没有开发环境、没有 FFmpeg、没有项目源码的干净 Windows 电脑完成测试。

## C. 每次构建命令

```powershell
cd E:\Workspace\Project_03_本地短视频批量混剪工作台
powershell -ExecutionPolicy Bypass -File .\tasks\check-installer-readiness.ps1

cargo test

powershell -ExecutionPolicy Bypass -File .\scripts\verify-user-test-package.ps1 -InstallAndLaunch
```
