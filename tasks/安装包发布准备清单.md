# Windows 安装包发布准备清单

## A. 内部测试包

- [ ] Windows 发布版程序可以编译。
- [ ] NSIS 安装器可以生成。
- [ ] 测试电脑已安装 FFmpeg，或者安装包已经内置 FFmpeg / FFprobe。
- [ ] 测试电脑已安全配置 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`。
- [ ] 安装后完成导入、切片、AI 分镜和导出。
- [ ] 卸载后程序文件可以正常清理，用户主动选择的素材和成片不能被删除。

## B. 发给外部普通用户前

- [ ] 安装包内置合法来源的 FFmpeg / FFprobe，并附许可证和来源说明。
- [ ] 不要求普通用户打开 PowerShell 配置环境变量。
- [ ] AI Key 采用“用户自己的 Key 安全保存”或“自建服务端代理”方案。
- [ ] 不把开发者公共 API Key 写进前端、安装包或普通配置文件。
- [ ] 收窄本地文件访问权限，避免默认允许整个电脑目录。
- [ ] 准备正式应用图标、版本说明、隐私说明和用户协议。
- [ ] 使用代码签名证书，减少 Windows SmartScreen 的未知发布者警告。
- [ ] 在一台没有开发环境、没有 FFmpeg、没有项目源码的干净 Windows 电脑完成测试。

## C. 每次构建命令

```powershell
cd E:\Workspace\Project_03_本地短视频批量混剪工作台
powershell -ExecutionPolicy Bypass -File .\tasks\check-installer-readiness.ps1
corepack pnpm build
cd .\src-tauri
cargo fmt -- --check
cargo check
cargo test ai_remix --lib
cd ..
corepack pnpm tauri build --bundles nsis
```
