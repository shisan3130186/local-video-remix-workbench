# 下一阶段基础功能分类

## 结论

基础功能不要一次全部开发。先解决“普通测试用户能不能安装并完成一次任务”，再做提高效率的功能，最后才做 TTS、字幕等大模块。

## 第一类：安装和首次启动，最高优先级

1. 内置 FFmpeg / FFprobe。
2. 首次启动环境检查。
3. AI 配置状态检查。
4. 默认输出目录和目录记忆。
5. 软件版本、错误日志导出和反馈入口。

验收标准：一台没有开发环境的电脑，安装后可以完成导入、切片、AI 分镜和导出。

## 第二类：MVP 基础易用性

1. 保存和重新打开当前项目。
2. 素材删除、重新命名和重新排序。
3. 自定义输出文件名。
4. 任务取消、失败重试和进度百分比。
5. 清理临时切片和磁盘空间提示。

验收标准：用户中途退出后不需要全部重做，失败时能恢复，生成文件容易管理。

## 第三类：竞品核心增强

1. TTS 文案配音。
2. 按配音时长调整镜头。
3. 自动字幕和字幕样式。
4. 一次生成多条不同版本。
5. 持久化素材画面描述，避免重复付费识别。

验收标准：输入文案后可以得到包含画面、语音和字幕的完整视频，并能批量生成差异版本。

## 用户确认后再开发

请从第一类或第二类中明确选择下一个功能。没有确认前，不同时开发 TTS、字幕、会员、复杂时间轴或自动发布。
