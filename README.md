# 本地短视频批量混剪工作台

## 项目定位

这是一个本地桌面端视频批量处理软件，目标是实现：
导入素材 → 视频预览 → 视频切片 → 随机混剪 → 批量导出。

## 当前阶段

V0.1：基础视频导入、预览、FFmpeg环境检测、基础导出。

## 技术栈

桌面端：
Tauri / Vue3 / TypeScript

视频处理：
FFmpeg / FFprobe

数据库：
SQLite

AI能力：
后续接入 TTS / ASR / OCR / 文案匹配。
